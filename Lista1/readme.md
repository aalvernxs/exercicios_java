# ☕ Exercícios de Java Básico — Aula 13

Resoluções dos exercícios de Java SE da **Aula 13** do curso gratuito da [Loiane Groner](http://www.loiane.com/2013/10/curso-java-basico-java-se-gratuito/), cobrindo entrada de dados, operações matemáticas e estruturas condicionais.

---

## 📚 Conteúdo

Os exercícios abordam os seguintes temas:

- Entrada de dados com `Scanner`
- Operações aritméticas básicas
- Conversões de unidades (metros → cm, Fahrenheit ↔ Celsius)
- Cálculo de médias, salário, área de figuras geométricas
- Cálculo de peso ideal
- Estruturas condicionais (`if/else`)
- Situações do dia a dia (loja de tintas, multa de pesca, download de arquivos)
