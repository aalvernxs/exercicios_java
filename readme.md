# ☕ Exercícios Java SE

Repositório de exercícios e práticas em **Java SE**, desenvolvidos durante meus estudos com o curso de Java da **Loiane Groner**. O objetivo é registrar minha evolução na linguagem, do básico até conceitos mais estruturados de lógica de programação.

## 📋 Sobre o Projeto

Cada pasta representa um bloco de estudo, agrupando exercícios por tema. O repositório é atualizado conforme avanço no curso, servindo como histórico de aprendizado e prática de fundamentos de Java.

## 🧠 Tópicos Cobertos

- Fundamentos da linguagem (variáveis, tipos primitivos, operadores)
- Entrada e processamento de dados (`Scanner`)
- Cálculos e lógica matemática aplicada
- Estruturas condicionais (`if`, `else`, `switch`)
- Estruturas de repetição (`for`, `while`, `do-while`)

## 📁 Estrutura do Repositório

```
exercicios_java/
├── Lista1/       → primeira lista de exercícios (fundamentos e lógica)
└── Loops/
    └── src/      → exercícios com estruturas de repetição
```

## 🛠️ Tecnologias

- Java SE
- IntelliJ IDEA

## 🚀 Como Rodar

1. Clone o repositório:
   ```
   git clone https://github.com/aalvernxs/exercicios_java.git
   ```
2. Abra a pasta desejada (`Lista1` ou `Loops/src`) na sua IDE de preferência.
3. Compile e execute a classe `.java` correspondente ao exercício:
   ```
   javac NomeDoArquivo.java
   java NomeDoArquivo
   ```
